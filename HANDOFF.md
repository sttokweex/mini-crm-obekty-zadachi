# Текст для руководителя

В системе есть объекты строительства и задачи по каждому объекту. Постановщик создаёт объекты, назначает задачи исполнителям и принимает результат либо возвращает его на доработку с объяснением. Исполнитель видит только свои задачи, берёт их в работу и отправляет на проверку. В карточке задачи видно, кто и когда менял статус, а также комментарий при возврате.

Ограничения работают в самой базе данных. Если исполнитель попробует обратиться к ней напрямую, он всё равно не получит чужие задачи и не сможет изменить чужую работу. База разрешает только предусмотренные шаги: например, нельзя сразу принять новую задачу или вернуть её без комментария. Историю изменений пользователь не может исправить или удалить. Регистрация закрыта, доступы выдаются вручную. Ключ с полными правами в приложении не используется.
